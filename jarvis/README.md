# J.A.R.V.I.S — עוזר קולי עתידני למחשב

אפליקציית מחשב ל-Windows בסגנון הג'רוויס של איירון מן: מסך שחור עם כדור פלזמה חי בתלת-ממד (אלפי חלקיקים, שלד גאודזי, ליבה בוערת, קרני אור וקשתות שמקיפות אותו) שמגיב לקול, ושולט במחשב לפי הקול שלך בלבד.

שלוש תצוגות בתפריט העליון: **Home** (רק הכדור), **Chat** (היסטוריית השיחה) ו-**Dashboard** (אפליקציות ונתוני מערכת). אפשר גם להגיד "תפתח את הדשבורד" / "תראה את הצ'אט" / "מסך הבית", או ללחוץ 1/2/3.

## המוח: לדבר איתו חופשי (AI)

עם מפתח API של Anthropic ג'רוויס מבין דיבור חופשי, לא רק פקודות קבועות. המוח הוא Claude, וג'רוויס משתמש בו כמו מנהל אישי:

- "תכניס לי את הסרטון החדש של מיסטר ביסט ואז תנמיך קצת" → מוצא, מנגן ומנמיך.
- "מה מזג האוויר מחר בתל אביב?" → מחפש ברשת ועונה בקול.
- "תזכיר לי בעוד עשר דקות להוציא את הפיצה" → טיימר עם תזכורת קולית.
- "תעבור לחלון של וורד ותקליד 'שלום לכולם'" → מנהל חלונות ומקליד.
- "תמצא את הקובץ של קורות החיים ותפתח אותו" → מחפש בתיקיות שלך.
- "תזכור שאני אוהד מכבי" → זוכר את זה גם בפעם הבאה.

**איך מפעילים:**
1. נכנסים ל-https://console.anthropic.com ← API Keys ← Create Key. השימוש בתשלום לפי שימוש.
2. אומרים "ג'רוויס, פתח את קובץ ההגדרות" ומדביקים את המפתח בשורה `api_key:` שבקטע `ai:`.
3. שומרים. בפינה העליונה יופיע **AI ONLINE**, בלי להפעיל מחדש.

פקודות פשוטות כמו "פתח כרום" או "מה השעה" רצות במחשב ומיד. כל השאר עובר למוח. אם אין אינטרנט או מפתח, ג'רוויס ממשיך לעבוד עם הפקודות הרגילות.

## זיהוי הקול שלך בלבד

בהפעלה הראשונה ג'רוויס מבקש לקרוא בקול 5 משפטים, ושומר "טביעת קול" במחשב שלך (שום דבר לא נשלח לאינטרנט).
מאותו רגע הוא מתעלם מכל קול אחר: טלוויזיה, אנשים אחרים בחדר, וגם הקול של עצמו.
ללמד את הקול מחדש: "ג'רוויס, למד את הקול שלי" או מתפריט האייקון ליד השעון.
להחמרה או להקלה משנים את `speaker.threshold` בקובץ ההגדרות.

> זיהוי דובר הוא שכבת נוחות, לא מנעול אבטחה. הקלטה איכותית של הקול שלך יכולה לעבור אותו, ולכן פעולות מסוכנות (כיבוי, התקנה, הסרה) תמיד מבקשות אישור.

## התקנה (Windows 10/11)

1. מורידים את התיקייה `jarvis` (או את כל הריפו).
2. לוחצים פעמיים על **`install.bat`**. אם Python לא מותקן, הקובץ מתקין אותו לבד. ההתקנה לוקחת 5 עד 15 דקות.
3. נוצר אייקון **JARVIS** על שולחן העבודה. לוחצים עליו וזהו.

בהפעלה הראשונה יורדים מודלים של זיהוי דיבור וזיהוי קול (בערך 500MB), ורק אחרי זה ג'רוויס מתחיל להקשיב.

זיהוי הדיבור עובד דרך גוגל ולוקח בערך שנייה. בלי אינטרנט הוא עובר לבד למודל Whisper שרץ במחשב, ואז זה איטי יותר. ביומן המערכת מופיעה שורת ⏱ עם זמן כל שלב בכל פקודה.

- `run.bat`: הפעלה בלי חלון שחור.
- `run_debug.bat`: הפעלה עם חלון שמציג שגיאות.
- `build_exe.bat`: בונה `dist\JARVIS\JARVIS.exe` עצמאי שאפשר להעביר למחשב אחר בלי Python.

## לתקן ולשנות בזמן שג'רוויס פועל 🔧

לא צריך לסגור ולהפעיל מחדש. כל שמירה של קובץ נטענת תוך פחות משנייה, ויומן המערכת (למטה מימין) מראה שהשינוי נקלט:

| מה משנים | איפה | איך פותחים |
|---|---|---|
| הגדרות: שם, צבעים, אפליקציות בפאנלים, אתרים, מיקרופון | `%APPDATA%\JARVIS\config.yaml` | "ג'רוויס, פתח את קובץ ההגדרות" או לחיצה על CONFIG |
| פקודות משלך ("בוקר טוב" = לפתוח חדשות + ספוטיפיי) | `%APPDATA%\JARVIS\commands.yaml` | "פתח את קובץ הפקודות" או COMMANDS |
| תוספים ב-Python עם יכולות חדשות | `%APPDATA%\JARVIS\plugins\*.py` | "פתח את תיקיית התוספים" |
| העיצוב והאנימציות (HTML/CSS/JS) | `jarvis\hud\` | התצוגה מתרעננת לבד |
| הבנת הפקודות וההתנהגות (Python) | `jarvis\brain\`, `jarvis\actions\` | "פתח את הקוד שלך" |

אם נשמרת טעות (שגיאת תחביר או YAML שבור), ג'רוויס **לא קורס**. הוא מציג את השגיאה ואת מספר השורה, וממשיך לעבוד עם הגרסה הקודמת עד שמתקנים.

דוגמה לתוסף (`plugins\weather.py`):

```python
from jarvis.plugin import command

@command("מה מזג האוויר", "weather")
def weather(ctx, text):
    ctx.search("מזג האוויר היום")
    return "הנה תחזית מזג האוויר."
```

## גרסת הטלפון 📱

אפליקציית ווב שמותקנת על מסך הבית כמו אפליקציה רגילה, עם אותו כור תלת-ממדי ואותו עיצוב (בתיקייה `mobile/`):

- **דיבור:** לוחצים על המיקרופון או על הכור ומדברים. אפשר גם להפעיל האזנה רציפה עם "ג'רוויס".
- **פעולות:** סרטון מדויק ביוטיוב, חיפוש, ניווט ב-Waze או Google Maps, וואטסאפ, חיוג, פתיחת אפליקציות, טיימרים עם רטט והתראה, ומצב סוללה.
- **אותו מוח AI:** את המפתח מדביקים במסך ההגדרות (⚙), והוא נשמר רק בטלפון.

**איך מעלים אותה לאוויר (פעם אחת, דרך Netlify):**
1. ב-Netlify: Add new site ← Import an existing project ← GitHub ← הריפו `yupebis`.
2. נותנים לאתר שם שמכיל `jarvis`, למשל `jarvis-yuval`. לפי השם, הבנייה יודעת להעלות את אפליקציית הטלפון.
3. Deploy. מקבלים כתובת כמו `https://jarvis-yuval.netlify.app`.
4. בטלפון פותחים את הכתובת:
   - ב-Android בכרום: ⋮ ← "הוסף למסך הבית".
   - באייפון ב-Safari: שיתוף ← "הוסף למסך הבית".

זיהוי דיבור עובד הכי טוב בכרום ב-Android וב-Safari באייפון.

## איך זה בנוי

```
jarvis/
├─ app.py           חלון שולחן העבודה (PySide6 + WebEngine), מגש מערכת, קיצור מקלדת
├─ core.py          המוח: צינור הקול, אישורים, טעינה חיה
├─ server.py        שרת מקומי (127.0.0.1 עם מפתח אקראי) שמחבר בין Python לממשק
├─ voice/           מיקרופון, Whisper (דיבור לטקסט), SpeechBrain (זיהוי דובר), Edge TTS (קול)
├─ brain/           intents.py מבין עברית ואנגלית · skills.py מבצע
├─ actions/         דפדפן ויוטיוב · אפליקציות · winget · מערכת
└─ hud/             ממשק תלת-ממדי ב-three.js עם bloom, נטען מקומית בלי אינטרנט
mobile/              גרסת הטלפון (PWA): אותו כור, זיהוי דיבור של הדפדפן, Claude ישירות מהטלפון
```

בדיקות: `python -m unittest discover -s tests`
