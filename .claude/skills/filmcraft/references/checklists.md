# Checklists

Runnable passes, not prose. Use the one that matches the task; each item is a yes/no you can actually check against the material.

---

## Intake gate (run FIRST, before any deliverable)
Answer each from the request + a sensible default; only a load-bearing gap that can't be defaulted becomes a question to the user (see SKILL.md "Step 0"). For each: **have it / defaulted it / must ask.**
- [ ] **Deliverable** — do I know the exact output (pages, beat sheet, shot list, coverage, notes)?
- [ ] **Format** — feature / short / series / K-drama / C-drama / limited / web / doc / MV / ad / social / sequel?
- [ ] **About** — do I know the governing idea, not just the plot?
- [ ] **Genre & tone** — the audience contract?
- [ ] **Length / runtime** target?
- [ ] **Audience / platform / language?**
- [ ] **Hard constraints** — budget tier, real people/IP, mandated ending, content limits?
- [ ] **(Critique)** do I have the *material* and the *maker's intent* to judge against?
- [ ] **("In the style of X")** which director, and do I have their `directors/` profile?
- [ ] Did I **default the small unknowns** and reserve questions for only what's load-bearing?
- [ ] Am I **asking before producing** (not drafting on a guessed premise), batching the gaps, each with a recommended default?

## Script self-edit pass (per scene)
- [ ] Does the scene have a **turn** — a value or knowledge that changes start to end? If not, cut or merge it.
- [ ] Whose scene is it? Does the driving character have a clear **objective**?
- [ ] Did I **arrive late and leave early** — enter at the latest moment, cut before the energy dies?
- [ ] Is any line **on-the-nose** (states the feeling/theme)? Replace with a tactic or an action.
- [ ] Do the characters sound **distinct** from each other?
- [ ] Are the action lines **filmable** (behavior, not interiority)?
- [ ] Is there a **specific, chosen detail** grounding the scene, or is it "a room"?
- [ ] Could I cut this scene and lose nothing? Then cut it.

## Script macro pass (whole script)
- [ ] Is the **protagonist active** — driving and choosing under cost, not rescued by events?
- [ ] Are **want** (external) and **need** (internal) both present and colliding?
- [ ] Does the **midpoint** cost the hero something and raise the stakes?
- [ ] Does the **climax test the theme**, not just resolve the plot?
- [ ] Is the **theme dramatized** through choices, never stated in a speech?
- [ ] Does causality hold — *therefore/but*, not *and then*?
- [ ] Can I write a clean, specific **logline**? If not, the spine is unclear.
- [ ] Is the ending **earned** (a cost paid), not frictionless?

## Director's prep pass (before the shoot)
- [ ] Do I know what **each scene is really about** (the one-line "about")?
- [ ] Is every scene **blocked** — actors staged for the power dynamic — before the camera is placed?
- [ ] Does every **shot have a story reason** (in the shot-list notes)?
- [ ] Is the **coverage** enough to cut the scene (master + singles + the key inserts)?
- [ ] Do I have a **playable objective** for each actor in each scene?
- [ ] Is the **180° line** decided; do eyelines and screen direction hold?
- [ ] Is the **lighting motivated** — is there an in-world source?
- [ ] What is the scene's **emotional peak**, and does the plan build to it?
- [ ] What can I **lose** if the day runs short (the "drop shots")?

## Coverage / critique pass (evaluating someone's work)
- [ ] Big-picture before line-level: **structure → scene → shot → frame**.
- [ ] Does each note name **where** (page/beat/timecode)?
- [ ] Does it name **what's broken** (the cause), not just the symptom?
- [ ] Does it imply **why** it breaks the experience?
- [ ] Did I find the **note behind the note** (the structural cause of the "boring")?
- [ ] Did I **diagnose** and leave the craftsperson's solution to them where appropriate?
- [ ] Did I lead with **what's working** so it survives the next pass?
- [ ] Am I judging it against **its own goal and format**, not a universal or my taste?

## Format-fit pass (is it the right shape?)
- [ ] **Feature:** one unified vision and an earned change across ~2h — not a bag of good scenes?
- [ ] **Short:** does it earn **one** idea completely — not trying to be a small feature?
- [ ] **Series:** does the premise **sustain and escalate** — an engine, not just a great pilot?
- [ ] **Documentary:** is the story **found in the edit**, honestly — access and real moments over polish?
- [ ] **Music video:** does the image **serve the track** and the artist's identity?
- [ ] **Commercial:** does it **sell one clear idea in 30–60s** without burying the message?
- [ ] **Social short:** does the **hook** land in 1–3 seconds and hold to the payoff?

## Sound & mix sanity pass
- [ ] Is **dialogue always intelligible** (everything ducks under it)?
- [ ] Is there **room tone / atmos** so edits don't pop?
- [ ] Is there **silence to spend** — or is the mix wall-to-wall?
- [ ] Does the **score add a layer** the picture lacks, or just duplicate the on-screen emotion?
