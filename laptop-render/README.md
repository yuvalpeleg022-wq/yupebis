# רינדור AI ל-4K 60fps במחשב (Windows)

אותו תהליך שרץ בענן, אבל על כרטיס המסך של המחשב שלך: Real-ESRGAN (הגדלה ל-4K) → מיזוג 30% מהמקור (נגד מראה "פלסטיק") → RIFE (60fps) → תיקון חיתוכי סצנה → H.265 10-bit בשתי גרסאות: HDR10 ו-SDR.

## איך מריצים
1. הורד את התיקייה `laptop-render` (בדף הענף ב-GitHub: **Code → Download ZIP**, ואז חלץ).
2. גרור את קובץ הווידאו ושחרר אותו **על `run.bat`**.
3. בהרצה הראשונה הסקריפט מוריד לבד את הכלים (~600MB): ffmpeg, Real-ESRGAN, RIFE.
4. הקבצים המוכנים נשמרים ליד הווידאו המקורי:
   `<שם>_4k60_ai_HDR10.mp4` ו-`<שם>_4k60_ai_SDR.mp4`

אם Windows מציג "Windows protected your PC" — לחץ **More info → Run anyway**.

## דרישות
- Windows 10/11, דרייבר גרפי מעודכן (NVIDIA / AMD / Intel).
- ~15GB פנויים בדיסק בזמן העבודה (נמחק בסוף).
- הסקריפט בוחר לבד את כרטיס המסך החזק ביותר (במחשב נייד עם שני כרטיסים — את ה-NVIDIA/AMD).

## הגדרות (לא חובה)
מ-PowerShell:
```
powershell -ExecutionPolicy Bypass -File render.ps1 -Video "C:\path\video.mp4" -Model realesrgan-x4plus -Blend 0.35 -Grain 7
```
| פרמטר | ברירת מחדל | מה זה |
|---|---|---|
| `-Model` | `realesr-animevideov3` | `realesrgan-x4plus` = יותר פרטים בצילום אמיתי, איטי יותר |
| `-Blend` | `0.30` | כמה מהמקור מוחזר מעל ה-AI (0.25–0.40) |
| `-Grain` | `5` | גרעין עדין (0 = כבוי) |
| `-Crf` | `12` | איכות קידוד (נמוך = איכותי וגדול יותר) |
| `-Preset` | `slow` | `medium` = קידוד מהיר יותר |
| `-Gpu` | אוטומטי | מספר כרטיס מסך ידני |

אם ההרצה נעצרה באמצע — פשוט הרץ שוב; שלבים שהסתיימו לא ירוצו מחדש.
