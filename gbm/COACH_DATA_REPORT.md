## In a new career

- Clubs whose real coach is unknown first receive a **real** unattached coach as a simulated in-game appointment (9 in a fresh career). These are flagged in the UI and in each coach's record; the data issue stays open.
- Fictional coaches are created only when no real coach can fill a playable club's head-coach post (0 needed with the current dataset). AI clubs fill assistant/specialist posts with real coaches only.
- Coach game ratings, traits, salaries and contract lengths are provisional gameplay estimates, never real-world claims.
